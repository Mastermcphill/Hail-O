# Codex Brand Spec (Optional)

## Core Identity
- Name: Codex
- Tagline: Build Faster, Ship Smarter
- Tone: modern, clean, precise, reliable

## Palette
- Primary: `#1A73E8`
- Accent: `#FF4081`
- Dark: `#0A0F2C`
- Light: `#F5F7FA`

## Typography
- Headings: Space Grotesk (700/500)
- Body: IBM Plex Sans (400/500/600)

## Logo Usage
- `logo.svg`: default color lockup for light backgrounds
- `logo_dark.svg`: monochrome lockup for dark backgrounds
- Keep clear space equal to icon bracket height around logo lockups
- Minimum recommended width:
  - Header lockup: 160px
  - Favicon/icon-only: 32px

## Delivered Assets
- SVG:
  - `logo.svg`
  - `logo_dark.svg`
- PNG:
  - `logo.png` (1x)
  - `logo@2x.png` (2x)
  - `logo_dark.png` (1x)
  - `logo_dark@2x.png` (2x)
- Favicon/icon placeholders:
  - `images/favicon.svg`
  - `images/favicon-1x.png`
  - `images/favicon-2x.png`
